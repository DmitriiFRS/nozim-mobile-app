# Готовые варианты стеклянных кнопок

Найдено и просмотрено 10 октября 2026 года.

## Основной вариант для визуального ориентира

[tomagranate/liquid-glass](https://github.com/tomagranate/liquid-glass) содержит движок стеклянного эффекта и готовые стилизованные примеры кнопок в [examples/demo/src/glass](https://github.com/tomagranate/liquid-glass/tree/master/examples/demo/src/glass). В README указан vanilla API `applyGlass()`, управление интенсивностью и метод очистки `destroy()`. Репозиторий опубликован под MIT.

Это подходящий готовый пример с бликом, округлой кромкой и рефракцией. Для нашего статического мобильного макета реализована самостоятельная облегчённая версия: CSS backdrop blur, полупрозрачная заливка, тонкая световая кромка и движущийся блик. Код библиотеки не скопирован и библиотека не подключена. Физическое преломление фона через SVG/WebGL в эту версию не входит.

## Дополнительный готовый пример

[Mael-667/Liquid-Glass-CSS](https://github.com/Mael-667/Liquid-Glass-CSS) предлагает готовый класс `.liquidBtn` для CSS/JS и [демо на сайте автора](https://mael-667.github.io/). Репозиторий имеет GPL-3.0; в проекте используется только как визуальный ориентир, его код не включён.

## Наша реализация

- `css/glass.css`: материал и CSS fallback.
- `js/glass-buttons.js`: `initGlassButtons(root, options)`.
- Опция `selector`, по умолчанию `[data-glass]`.
- Опция `intensity` от 0 до 2, по умолчанию 1.
- Возвращаемое значение: функция очистки обработчиков и анимаций.
- Pointer Events для мыши и touch, feedback для клика клавиатурой.
- При `prefers-reduced-motion` движение отключается.
- При `prefers-reduced-transparency` и отсутствии backdrop-filter используется непрозрачная заливка.

Официальный Apple Liquid Glass относится к платформам Apple. Здесь используется веб-аппроксимация материала.
